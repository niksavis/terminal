- **A setup run that changes nothing is faster.** Setup checks the WSL release tools in one `wsl.exe` call and looks up their latest releases in parallel, on Windows too. It finds duplicate system copies in one call, and skips the basicly `cli-tools` skill install when the recorded harness version is current. Measured on one WSL machine: 15 tool checks went from 17.1 s to 1.7 s, the duplicate check from 5.8 s to 0.1 s (term-uuvvl7).
