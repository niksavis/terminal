- **WSL setup checks lazygit and uv with the other release tools.** Setup reads the installed and latest lazygit and uv in the same `wsl.exe` call as the 15 release tools, instead of 4 more calls. In WSL, lazygit now updates like the other release tools: `--update` updates it, and a run without `--update` names the newer release instead of asking. A lazygit copy that is only in `/usr/local/bin` gets a user-local copy in `~/.local/bin`, and setup then reports the two copies (term-uuvvl7).
